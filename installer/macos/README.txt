PremiereBind 1.0.0 for macOS

1. Quit Premiere Pro.
2. Open “PremiereBind Installer.pkg” and complete the installation.
3. Open Premiere Pro, then choose Window > Extensions > PremiereBind.

This installer supports both Apple Silicon and Intel Macs. It installs the panel, companion app, automatic startup, CEP configuration, and .prbind file support.

If macOS blocks the unsigned installer:
1. Open System Settings > Privacy & Security.
2. Scroll to the security message for PremiereBind and click Open Anyway.
3. Confirm Open, then run the installer again.

When PremiereBind opens for the first time, macOS asks for Accessibility access. Enable PremiereBind Companion in System Settings > Privacy & Security > Accessibility. This permission is required for global shortcuts and for transferring clips with native Premiere transitions. The panel detects the permission automatically; you do not need to restart Premiere Pro.
